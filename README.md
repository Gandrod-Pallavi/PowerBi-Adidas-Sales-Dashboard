# Adidas Sales Analysis Dashboard 📊

📌 Project Overview

This is my first Power BI dashboard project, created to analyze Adidas sales data and understand sales performance across different regions,
products, retailers, and time periods.

The dashboard provides interactive visualizations and key performance indicators (KPIs) to make the data easier to understand and analyze.

## 🛠️ Tools & Technologies Used

- Power BI
- Power Query
- DAX
- Excel
- Data Visualization

## 📊 Dashboard Features

The dashboard includes:

- Total Sales
- Total Profit
- Total Units Sold
- Sales by Region
- Sales by Product
- Sales by Retailer
- Sales by Time Period
- Profit Analysis
- Interactive Slicers and Filters
- KPI Cards
- Charts and Visualizations

## 🔄 Data Preparation

The data was cleaned and transformed using Power Query.

The main steps included:

- Removing unnecessary data
- Handling missing values
- Changing data types
- Cleaning and formatting columns
- Creating calculated columns
- Preparing the data for analysis

## 📈 Data Analysis

DAX measures were created to calculate important business metrics such as:

- Total Sales
- Total Profit
- Total Units Sold
- Average Sales
- Profit-related metrics

## 🎯 Project Objective

The main objective of this project is to practice data cleaning, data transformation, data modeling, DAX,
and dashboard creation using Power BI.
